# Ashen Wijenayake – Portfolio (Next.js + TypeScript + Tailwind)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

- All content lives in `lib/data.ts` (projects, experience, skills, stats, certifications, links).
- Add a `GitHub` repo to a project by filling the last field of its row in `PROJ`.
- Colours and fonts are CSS variables at the top of `app/globals.css`.
